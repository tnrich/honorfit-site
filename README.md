# HonorFit Blocker — website

Marketing, support, and privacy pages for HonorFit Blocker (honorfitapp.com),
served via GitHub Pages from the public `tnrich/honorfit-site` repo.

**The source lives in the app repo (`tnrich/pushup`, `site/`).** That repo
publishes here with `bun run site:deploy` (`git subtree push --prefix=site`).
Don't commit to `honorfit-site` directly: its history must stay a fast-forward
of what the subtree push produces.
